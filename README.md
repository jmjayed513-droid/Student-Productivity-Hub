# Student Productivity Hub

A responsive student productivity website designed to help students organize their academic activities, manage daily tasks, and track their study progress.

## Features

- Responsive Navigation Bar
- Student Dashboard
- Task Management
- Add New Tasks
- Mark Tasks as Completed
- Study Progress Tracker
- Responsive Design for Mobile and Desktop

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## Project Structure

```text
Student-Productivity-Hub/
│
├── index.html
├── .gitignore
│
├── src/
│   └── input.css
│
└── dist/
    └── output.css
```

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/jmjayed513-droid/Student-Productivity-Hub.git
```

2. Open the project folder in VS Code.

3. Install dependencies:

```bash
npm install
```

4. Run Tailwind CSS:

```bash
npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css --watch
```

5. Open `index.html` using Live Server.
